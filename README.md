# 🎹 KG Piseiro Keys

Teclado de piseiro para Android com sanfona sintetizada, ritmos automáticos e acordes.

## 📲 Baixar APK

**[⬇️ BAIXAR KG PISEIRO KEYS PARA ANDROID](https://github.com/riftsdev/Piseiro-Keys/releases/latest/download/KG-Piseiro-Keys.apk)**

> O link funciona após a primeira compilação e publicação bem-sucedida em [Actions](https://github.com/riftsdev/Piseiro-Keys/actions). É um APK de teste, não uma versão da Play Store.

## 🎹 Testar no navegador

[Abra o teclado HTML](https://riftsdev.github.io/Piseiro-Keys/) (requer GitHub Pages ativado) ou baixe [index.html](./index.html).

## Recursos
- Teclas multitouch
- Sanfona, lead, órgão, piano e metais sintetizados
- Ritmos de acompanhamento, acordes e virada
- Modo paisagem para celular

## Compilar
O GitHub Actions compila o APK e publica automaticamente na release `latest` a cada alteração na branch `main`. O workflow precisa de permissão de escrita para releases.

**Nota:** exercícios de acordes não são uma transcrição exata de “Vai Matar Papai”.
