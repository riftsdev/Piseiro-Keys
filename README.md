# KG Piseiro Keys 3.0
Teclado virtual para Android e navegadores móveis, com sanfona sintetizada, acordes e batida automática.

## Usar
Abra `index.html` no navegador e toque em **ATIVAR SOM**. Para instalar no Android, abra a aba **Actions**, execute **Build Android APK** e baixe o artefato `KG-Piseiro-Keys-debug-apk` após uma execução bem-sucedida.

O APK é de depuração, não assinado para publicação na Play Store. Timbres são sintetizados, não samples reais. A sequência de acordes é exercício didático, não transcrição oficial.
